## Where the project is (2026-11-15)

XNU boots on the Pixel 6a, mounts the iOS 16.7 root from `userdata`, and reaches the lock screen and home screen.
Now working: GPU acceleration, Wi-Fi with real internet, Bluetooth, and touch. **No audio playback yet.**

| Area | Result | Runs |
|---|---|---|
| GPU | smooth UI at about 50 fps with the GPU at its lowest clock (150 MHz): rendered 50.6 / 50.6 pooled, slowest step 48.4 / 48.6, 600 s bench with full Wi-Fi load (bars 50 / 45 met) | `155b`, `8177` |
| Frames on the panel | 49.0 drawn presents per second with the pacing fix: the 50/s bar is **not met yet** | `18e1` |
| Wi-Fi | joins WPA2 networks, real internet (address, route, DNS, HTTPS: 9 of 9 checks), TCP download 188.1 and 285.4 Mbit/s | `155b`, `8177` |
| Bluetooth | pairs and connects; a headset paired by hand in Settings | job 1308 |
| Touch | a real finger: 5791 touch interrupts, none empty, no storm | job 1308 |

This configuration runs 5 of the 8 CPU cores, CPU A76 at 1663 MHz and X1 at 1826 MHz (static), GPU 150 MHz, memory 1352 MHz.
A boot needs the PixOS shim and the iOS `userdata` root ([Try it](TRY.md)). The only partition ever written is `userdata`.

Disclaimer: AI was used heavily to make this run on Pixel 6a; it is based on ios-sweet.

**Known issues** (observed):

- No audio output yet: the phone has no speaker/codec driver; with a real headset A2DP pairs and the stream configures (SBC 44.1 kHz, bt-va3), but iOS never sends Start, so no sound plays.
- Drawn presents reaching the panel are 49.0 per second (run 18e1) against the bar of 50: not met. About 1.8 per second of swaps are still lost when a third swap lands inside the hold.
- This config runs 5 of the 8 CPU cores, CPU A76 at 1663 MHz and X1 at 1826 MHz (static), GPU 150 MHz, memory 1352 MHz. A boot needs the PixOS shim and the iOS userdata root.
- UDP download loses packets under heavy load: 27.3 % and 39.5 % in the two bench boots (155b, 8177); 2.4 % in one run after the bench, 0 in others. The cause is not found.
- The iOS daemon lskdd exits about once a second all boot long (14 to 16 ms each) and is restarted; cause not found, not disabled.
- Cold start counts in the bench: the first 13 s cost about 0.17 pooled fps; about 593 MB of UFS writes in 10 min from an unknown writer.
- Spotlight: a band under the status bar draws as transparent black; the magnifier glyph is missing in the search field (2026-11-11 list, not re-checked).
- The joined network shows a "Weak Security" label in Settings.
- Not yet: audio playback, cellular, camera, sensors, Face ID / fingerprint, sleep/wake.

## Known gaps we track

Every stub, ignored value or refused call prints one loud `GAP` line in the log, so missing pieces show up in every run instead of
failing silently (see [Method](METHOD.md)). The visible ones today are the known issues in the feature list above.
