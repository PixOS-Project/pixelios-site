# Milestones

**Last verified: 2026-11-16.** How the port got from "our code runs" to an iPhone UI with GPU, Wi-Fi and Bluetooth, one milestone at a time.
Each milestone has its own page with the same headings: **the goal, what was done, how it was proven, what it unlocked, and the dead ends**.

## The milestones

| | Milestone | When | State | Proof in one line (*observed on hardware*) |
|---|---|---|---|---|
| M0 | [First boot: shim, XNU, root file system](milestones/first-boot.md) | 2026-10-20/21 | done | `launchd` runs from the `userdata` root |
| M1 | [SpringBoard: the iPhone UI](milestones/springboard.md) | 2026-10-22 | done | lock and home screen, 8 cores (run `usbnet4-cpus8`), touch |
| M7 | [Hands-free test loop](milestones/test-loop.md) | 2026-10-22 to 11-09 | done | a panic and a hang both return to fastboot (runs `20261107T145123Z-panic-self-recover`, `ar-c-wdttest`) |
| M9 | [GPU: 55 frames/s](milestones/gpu.md) | 2026-10-23 to 11-11 | done; 60 open | slowest navigation step 56.6 (run `gputest-nav43`) |
| M8 | [Wi-Fi in Settings](milestones/wifi.md) | 2026-10-21 to 11-11 | done | joined from Settings with a DHCP lease (runs `wlan-wui-f2`, `wlan-wui-g`) |
| M13 | [Bluetooth on the stock daemon](milestones/bluetooth.md) | 2026-11-03 to 11-11 | done | scan, connect, pair, bond after reboot (runs `bt-pr3`, `bt-hotpair`) |
| M10 | [Charging](milestones/charging.md) | 2026-11-10 | done, one run | battery current positive at 875 mA (run `chg-p3`) |
| | [Everything at once, at low clocks](milestones/all-on-low-clock.md) | 2026-11-11 to 11-15 | met, except drawn presents 49.0 of 50 | rendered 50.6 frames/s at 150 MHz with real internet, two boots (runs `155b`, `8177`) |
| M12, M5, M11, M6, M14 | [Open: audio, keys, boot without a PC, sleep, cellular and the rest](milestones/open.md) | | open | |

"Usable phone" = boots without a PC, a stable GUI at 60 frames/s, touch and buttons, Wi-Fi, Bluetooth, sound, charging. We are not there.
